# HiJOY — Dress the dream

Три ботанічні композиції з паралаксом, наближення квітки з оком і порожній чорний екран для наступного розділу.

## Локальний запуск

Потрібен Node.js. Встановлення залежностей не потрібне.

```sh
npm start
```

Відкрити http://127.0.0.1:4173. Прокрутка, клавіші Page Down / Page Up та сенсорні жести керують рухом. Кнопка першого екрана переходить до другої композиції. Логотип повертає на початок.

## Структура

- `dist/index.html` — текст і окремі шари композиції.
- `dist/styles.css` — адаптивна композиція та шрифти Limelight, Italiana, Manrope.
- `dist/app.js` — анімація, прив'язана до прокрутки. Позиції сцен: 0, 1.3, 2.6; завершення: 4.45.
- `dist/assets/` — 21 оптимізоване WebP-зображення з актуальних PNG. Прозорі поля обрізані, пропорції збережені. Оригінали залишені в корені без змін.
- `.next-chapter` в HTML — порожній чорний розділ для продовження сайту.

25 шарів мають окремі параметри в HTML: `data-depth` (глибина), `data-exit-x/y` (напрям розходження у відсотках екрана), `data-turn` (поворот), `data-delay` (затримка виходу), `data-lag` (інерція у мілісекундах), `data-pointer` (реакція на курсор), `data-arc` (дуга руху). Позиція та ширина задаються через `--x`, `--y`, `--w`; мобільне розміщення — в CSS.

Темна підкладка кожної з перших двох сцен закриває наступну композицію. Під час руху шарів підкладка відкривається від центру, а задній план наближається. Фінальна квітка збільшується відносно зіниці.

Підтримується системна опція зменшення руху: зміщення, обертання, масштабування та реакція на курсор вимикаються, переходи відбуваються через прозорість. Анімаційний цикл зупиняється, коли сцена нерухома, та призупиняється у прихованій вкладці.

Сайт статичний: для розміщення потрібен лише вміст `dist/`. Шрифти завантажуються з Google Fonts.
