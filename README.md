# HiJOY — Dress the dream

## Розміщення на Vercel

Імпортуйте репозиторій із гілкою `main`. Root Directory має бути коренем репозиторію (залиште порожнім). Файл `vercel.json` задає Framework Preset `Other`, перевірку JavaScript командою `npm run check` та Output Directory `dist`.

Сайт уже містить готові статичні файли: `dist/index.html`, стилі, JavaScript та зображення. `npm start` запускає лише локальний сервер; на Vercel його запускати не потрібно. Після змін у `main` підключений Vercel створює нове розгортання.

Три ботанічні композиції з паралаксом, проліт крізь квітку з оком і четверта сцена, що послідовно складається з чотирьох зображень.

## Локальний запуск

Потрібен Node.js. Встановлення залежностей не потрібне.

```sh
npm start
```

Відкрити http://127.0.0.1:4173. Прокрутка, клавіші Page Down / Page Up та сенсорні жести керують рухом. Кнопка першого екрана переходить до другої композиції. Логотип повертає на початок.

## Структура

- `dist/index.html` — текст і окремі шари композиції.
- `dist/styles.css` — адаптивна композиція та шрифти Limelight, Italiana, Manrope.
- `dist/app.js` — анімація, прив'язана до прокрутки. Позиції сцен: 0, 1.3, 2.6; складання четвертої: 4.48–7.32; завершення: 7.8.
- `dist/assets/` — 25 оптимізованих WebP-зображень. У перших 21 обрізані прозорі поля; для 4-1–4-4 збережено спільне полотно 1672×941 для точного суміщення. Оригінали залишені в корені без змін.
- `.assembly` в HTML — четверта сцена після затемнення.

31 шар має окремі параметри в HTML: `data-depth` (глибина), `data-exit-x/y` (напрям розходження у відсотках екрана), `data-turn` (поворот), `data-delay` (затримка виходу), `data-lag` (інерція у мілісекундах), `data-pointer` (реакція на курсор), `data-arc` (дуга руху). Позиція та ширина задаються через `--x`, `--y`, `--w`; мобільне розміщення — в CSS.

Верхні ліві та праві елементи першої сцени зміщені до центру на 20% своєї відстані до нього; це зміщення застосовується на всіх розмірах екрана.

Наступна композиція одразу видима з прозорістю 22%, дальня — 9%. Другий шар починає рух збільшеним на 19–36% і ближчим до центру. Під час прокрутки елементи зменшуються до своїх розмірів, розходяться до боків та розвертаються у фінальні позиції. Прозорість і легке розмиття поступово зникають. Круглих масок і підкладок між сценами немає.

`data-entry-scale`, `data-entry-spread` і `data-entry-turn` керують початковим розміром, наближенням до центру та розворотом. Рука з квітами має `data-late-entry`: вона виїжджає з лівого краю між позиціями прокрутки 0.7 і 1.22 та починає вихід пізніше. Метелики мають різні дугоподібні траєкторії, нахил на поворотах і легкий рух крил, прив'язані до прокрутки через `data-flight` та `data-flight-phase`. Фінальна квітка збільшується відносно зіниці.

Підтримується системна опція зменшення руху: зміщення, обертання, масштабування та реакція на курсор вимикаються, переходи відбуваються через прозорість. Анімаційний цикл зупиняється, коли сцена нерухома, та призупиняється у прихованій вкладці.

Сайт статичний: для розміщення потрібен лише вміст `dist/`. Шрифти завантажуються з Google Fonts.

Третя сцена має 12 незалежних шарів: далекі сади, верхнє квіткове обрамлення, ліани, основні колажі й два метелики з різними траєкторіями. Нижній край оновленого зображення з лимонами показано без градієнтної маски.

Квітка з оком проявляється від позиції 0.78, зростає вже на другому екрані й прискорює наближення після 2.76. Перший заголовок збільшується до 2.2 раза на відрізку 0.1–0.7, другий — до 2.4 раза на відрізку 1.37–2.12; обидва починають зникати приблизно посередині наближення, раніше відкриваючи композицію. Опис із кнопкою рухаються окремо вниз. Опис набрано великими літерами Manrope Regular; нижню підказку прокрутки прибрано. При зменшенні руху масштабування й виїзд вимкнені.

Четверта сцена: 4-1 (рослинний передній план) починає рух на 4.48, 4-2 (столик) — на 5.12, 4-3 (моделі) — на 5.8, 4-4 (заднє обрамлення) — на 6.5. Кожна деталь має власний напрям входу, масштаб, поворот, інерцію та реакцію на курсор. Порядок накладання зберігає людей перед обрамленням, а рослини — на передньому плані. Після складання — м'яке загальне наближення; зворотна прокрутка розбирає сцену в протилежному порядку. Довжину сторінки збільшено пропорційно, темп перших трьох сцен збережено.
